Случайные задания для развития и поддержания креативности от designworkout Димы Барбанеля (взяты из открытых источников).

Кнопка "Задание" - всё просто: получай задание, выполняй, не трать много времени.

Кнопка "Ревью" - тут сложнее: пиши номер выполненного задания. В ответ ты получишь готовый промт для ИИ. Его нужно скопировать и вместе с фотками выполненного задания загрузить в одну из ИИ (Deepseek, Chatgpt, Gemini). ИИ даст обратную связь по твоей работе.
